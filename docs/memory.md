## What GrayDB is NOW (v0.4-wedge, ratified after external GPT review + user challenge)
A read-only PostgreSQL-native search + analytics LAYER, not a database of record. Attaches to customer's existing PG via logical replication (pgoutput) → GrayDB durable logical log → materializes columnar (embedded DataFusion over S3 segments) + search (Tantivy BM25/vector) → queried through STOCK PG + extension (no fork). Killer property: no sync pipeline, and every query proves its exact source LSN (`strong | bounded(X) | eventual`, graydb.freshness). Replaces: Postgres → Debezium → Kafka → Elasticsearch/ClickHouse.
